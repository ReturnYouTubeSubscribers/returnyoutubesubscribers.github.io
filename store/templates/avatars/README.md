# Channel pictures for the screenshots

Save each channel's profile picture here (square, at least 240x240, JPEG), then run
`npm run assets`. Any file that's missing falls back to the channel's initials.

| File | Channel |
| --- | --- |
| `mrbeast.jpg` | MrBeast (also copy to `assets/avatars/mrbeast.jpg` for the homepage) |
| `mrbeast-gaming.jpg` | MrBeast Gaming |
| `beast-philanthropy.jpg` | Beast Philanthropy |
| `sfmg.png` | Straight From MG (already here) |

Before publishing to the stores, note that Google, Mozilla and Apple can reject listings
that use another creator's name or picture in a way that suggests endorsement. Straight From MG
is the safest choice for store images; the MrBeast pictures are fine for the website.
